# Q2 实施细则（在查看预测系数和误差之前固定）

2026-09-28。延续 Q2_original_protocol.md，以下是为可复现实现补充的规则。不是外部注册的预注册试验。

## 数据与样本

- 先隔离哈希完全相同而日期不同的 14-1002.csv 与 15-0930.csv，不猜测真实归属。此前用户确认的 sales_data.csv 作为9月30日旧快照，单独保留；不拼接争议新文件。
- 普通100 Level、Section101–120、数字Row1–22、价格有效、预定开场前。逐条等权；Qty0未知。重复候选保留，并作去重敏感性。原始值不改写。
- 研究快照为纽约20:00，2026-07-01至2026-09-27。7月提供初始化训练，8月1日起做滚动预测；此前1月开售阶段不作为本次3天动量的评价期。
- 每文件的保守完整日截至点=最后记录时间之前最近一次纽约20:00。这只是数据完整性的操作性假设，并非平台确认。未达到该时点的窗口不评价。
- 每个72小时窗口至少5条、至少2个Section。整个未来窗口必须在开场前完成，主模型距开场>3天；本研究不回答最后72小时内的3天预测。

## 可比价格（每个决策时点重新拟合）

- 用截至t之前60天内的合格原始记录拟合log价格：Section、数字Row、来源、Qty组、场次与售出日固定效应，加log(1+距开场天数)的分段线性项（结点7/14/30/60天）。
- 至少500条训练记录；先调去Section/Row/来源/Qty构成影响，保留该场价格与时间变化。坐席或来源类别在训练中从未出现的记录不生成调整价格。源代码输出各日训练截至时间和样本量。
- t时模型冻结，同时用于该时点过去和未来各窗口；未来数据不重新训练t的价格调整系数。模型仅是可比价格估计，不是官方票面价。
- 主模型用sh+vs并作来源调整；sh单一来源另算一次。原始audit极值标记含全样本信息，仅供检查，不能据此在预测中删点。固定绝对价格审查上限$10,000只作单独敏感性。

## 信号、标签、共同市场

- A=(t−6天,t−3天]，B=(t−3天,t]，C=(t,t+3天]。x=median(log调整价格B)−median(log调整价格A)；y=median(log调整价格C)−median(log调整价格B)。这是72小时窗口中位水平之差，不是精确到t的可执行报价收益。
- 共享端点验证：用固定内容哈希将B分为B0/B1，x_split=B0−A，y_split=C−B1；每半至少5条、2个Section。仅把它当重要诊断：拆分能减少共享误差，但不能排除座位遗漏与模型估计误差。
- 不共享窗口验证：y_nonoverlap=D−C，D=(t+3天,t+6天]。必须另列为未来6天内的后3天变化。
- 同期相对收益诊断：全样本回归y~x+倒计时非线性项+场次固定效应+预测日期固定效应。日期效应吸收同日共同变动，仅用于事后关联检验，不进入实时预测。
- 可交易时点的共同市场控制：其他场次同一时点x的等权中位数（剔除本场，至少5场）。预测只使用过去市场信号，不使用未来市场收益或未来日期系数。仅代表Harry/MSG内部共同因子，非全美国票务市场。

## 滚动评价与不确定性

- 8月1日起每天，用标签结束时刻<=t的历史样本拟合。候选与基线使用相同可评价样本，最少120条、15个预测日。训练标签未成熟则不准进入训练。
- B0=不变；B1=倒计时+场次+过去市场信号；B2=B1+本场过去3天收益，均简单OLS，不调参、不筛选最优参数。
- 另做6天训练间隔敏感性，缓解相邻训练标签与测试信号窗口的重叠。日期滚动是历史模拟，不宣称真正前瞻测试；下载记录没有平台首次可见时间，另列延迟问题。
- 按事件与预测日历周作双向聚类；同时列单维聚类标准误，主要区间保守使用三者中最大的方差，t自由度取较小簇数减1。日期周簇仍不能完全解决跨周重叠，所以还做按7天日历块重抽样的OOS损失差区间。
- 报告MAE/RMSE（log百分点）、方向准确率、可评价覆盖、分时期及分场次差异；所有规定检验均报告，不因结果改成“反转策略”。正斜率才支持持续下跌的动量假说。
- 新日期的未成熟标签单列；至少下一次更新后才可验证。即使统计预测改善，也无可执行报价、费用或成交概率，因此不计算策略PnL。

## Q3 新闻边界

- 新闻只整理出处、发布日期、事件日与证据等级；未知首次发布时间不得填造。不根据报道情绪直接构造未经测试的交易信号。
- 驻演疲劳、二级市场供给、新增城市替代、周末/首末场/Harryween、倒计时与整体现价变化应区分。
- 在单艺人单场馆中，累计已演场数是日历日期的确定函数，与完整日历固定效应共线；逐场固定效应也会吸收固定演出顺序。不能声称同时完全控制两者后识别疲劳因果效应。
